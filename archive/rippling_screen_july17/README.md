# Today's Grind

## Order

1. Template diagnostic: write every core pattern from memory.
2. Priority problems: solve the reported/high-probability Rippling patterns.
3. Full mock: 60 minutes, two questions, spoken explanation throughout.
4. Final review: record mistakes and rewrite only weak templates.

## Suggested schedule

- **Block 1 — Diagnostic (75 min):** `01_templates/`
- **Block 2 — Targeted problems (2–3 hr):** `02_priority_problems/`
- **Block 3 — Break and food**
- **Block 4 — Mock interview (60 min):** `03_mock_interview/`
- **Block 5 — Repair weak spots (60–90 min)**
- **Final pass (30 min):** complexity sheet and mistake log
- Stop at a sensible hour and sleep.

## Interview answer loop

For every question:

1. Restate the problem and clarify inputs, outputs, and constraints.
2. Give a brute-force approach and its complexity.
3. Explain the optimized invariant before coding.
4. Write clean code while narrating data-structure choices.
5. Trace one normal case and one edge case.
6. State time and auxiliary-space complexity with justification.

## Directory map

- `01_templates/diagnostic.py` — closed-book template test
- `02_priority_problems/` — today's six highest-value problems
- `03_mock_interview/` — untouched until the timed mock
- `04_review/` — mistake log and complexity recall sheet
