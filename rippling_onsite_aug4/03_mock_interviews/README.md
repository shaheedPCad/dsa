# Mock Interviews

Run these as 1 hour rounds:

- 5 minutes: clarify and plan question 1
- 15-20 minutes: solve question 1
- 5 minutes: test and complexity
- 5 minutes: clarify and plan question 2
- 20-25 minutes: solve question 2
- 5 minutes: test, complexity, follow-up

## Mock Pair Types

- Easy-medium implementation + medium graph
- Medium intervals/heap + medium BFS
- Medium topo + medium hashing/string
- Matrix custom problem + standard LeetCode medium

After each mock, update `../04_review/mistake_log.md`.
