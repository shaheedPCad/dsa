# Complexity Drill

Know these cold:

| Pattern | Time | Space |
|---|---:|---:|
| BFS/DFS adjacency list | O(V + E) | O(V) |
| BFS/DFS grid | O(R * C) | O(R * C) |
| Topological sort | O(V + E) | O(V + E) |
| Union Find operations | Almost O(1), amortized | O(V) |
| Heap push/pop | O(log n) | O(n) |
| Heap peek | O(1) | O(n) |
| Heapify list | O(n) | O(1) or O(n), depending on implementation |
| Sort | O(n log n) | language-dependent |
| Binary search | O(log n) | O(1) |
| Sliding window | O(n) | usually O(k) or O(1) |
