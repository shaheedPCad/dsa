# Edge Case Checklist

## General

- Empty input
- One element
- Duplicates
- Already sorted
- Reverse sorted
- All same value
- Missing key/node

## Graphs

- Disconnected graph
- Cycle
- Self-loop
- Duplicate edges
- Directed vs undirected mismatch
- Start equals target
- Target unreachable

## Grids

- Empty grid
- One cell
- Uneven row lengths
- Boundary cells
- Diagonal adjacency question
- All land / all water

## Intervals

- Touching intervals
- Fully nested intervals
- Same start time
- Same end time
- Empty intervals list
