# Standard Traversal

## Must Know

- Build adjacency list from edges
- DFS recursive
- DFS iterative
- BFS from a start node
- Traverse disconnected graph
- Count connected components
- Detect cycles at a basic level

## Drill Problems

- Number of Provinces
- Find Eventual Safe States
- Keys and Rooms
- Reorder Routes to Make All Paths Lead to City Zero
- All Paths From Source to Target
- Critical Connections in a Network, if you want a hard stretch

## Questions To Answer Out Loud

- Is the graph directed or undirected?
- What does visited mean in this problem?
- Do I mark visited when adding to the queue or when popping?
- Do I need to visit every node or only nodes reachable from one start?
