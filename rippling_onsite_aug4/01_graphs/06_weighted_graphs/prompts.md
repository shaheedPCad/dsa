# Weighted Graphs

## Must Know

If weights represent multiplication or ratios, BFS/DFS can work when you only
need any path product.

If weights represent shortest cost or minimum distance, use Dijkstra when all
edge weights are non-negative.

## Drill Problems

- Evaluate Division
- Path with Maximum Probability
- Cheapest Flights Within K Stops

## Questions To Ask

- Do I need any valid path or the optimal path?
- Are weights positive?
- Is there a limit on number of stops?
- Should unknown nodes return a sentinel value?
